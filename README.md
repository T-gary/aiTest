# 极简商城

版本：**v0.6.9**

Vue3 + Rust(axum) + MySQL 的极简商城。前台只展示商品，没有买家和商家之分；后台提供账号注册/审核、商品录入和运营看板。PC 与安卓浏览器共用同一套响应式页面。

## 功能

### 前台 `/`

参考京东的三栏布局：

- **顶部**：搜索框（按商品名称搜索）。
- **左栏**：商品分类列表，带各分类商品数，点选即筛选（分类由商品自动汇总）。
- **中栏**：顶部促销轮播（后台勾选「首页轮播」的商品，4 秒自动切换、可点圆点切换）；下面是商品栅格，可在中间区独立滚动，每页 20 条。
- **右栏**：悬浮工具栏（首页 / 购物车 / 我的 / 客服 / 移动版 / 插件版 / 反馈 / 调研，仿京东），**全站所有页面显示**，唯独 `/admin` 后台管理页不显示。
  - 首页、购物车、我的为可点链接；其余为占位灰显。
  - **「移动版」**：点击切到手机预览（390×844 设备框，页面按容器宽度自动走手机样式），再点一次或按 `Esc` 回到桌面版；选择记在 `localStorage`。
- **中间商品区**：PC 端栅格布局（每列 200px 起，自适应 3~6 列），中间区独立滚动，左右两栏固定，整页不出滚动条。
- **移动版首页**：顶部红色 tabs + 搜索 + 可横滑分类条，往下依次是轮播、限时秒杀横滑、两列商品瀑布（右下角圆形加购按钮）、底部 5 个 tab 导航（首页/分类/消息/购物车/我的）。
  - 移动版顶部（轮播以上）：红色 tabs 条（特价 / 首页 / 秒送·外卖 / 新品 + 右侧「3C新品 换新0元购」）、白底圆角搜索框（扫码图标 + 输入 + 红色搜索按钮）、可横向滑动的分类条（关注 / 推荐 / 国家补贴 + 真实分类 + 右侧 ≡）。
  - **消息页 `/messages`**：红色头部（标题 / 清除未读 / ···）、5 个消息分类入口（会话·物流·提醒·优惠·互动）、全部/购物/秒送筛选、消息列表与「没有更多消息了」、底部「推荐」商品栅格（标题吸顶）。
  - 「消息」tab 带未读角标（演示数据存 localStorage），点「清除未读」清零。
  - 搜索框 placeholder 每 3 秒轮播（用真实分类名），**输入框为空时点搜索按钮，就用当前轮播词搜索**；搜完清空输入框，可连续点。
  - 向下滚动超过 400px 后，右下角出现圆形「回到顶部」按钮（40px，距边 12px，距底 68px）。
  - 右下角固定「立即领奖」浮层（礼物图标 + 文案 + 关闭 ×），点击滚到「限时秒杀」；关闭只对本次生效，重新进入首页再次出现。
  - 「限时秒杀」横滑：触控/滚动条可横向滚动，桌面鼠标滚轮也会转成横向滚动。
  - 左下角「直播」浮层：**视频内嵌在浮层里自动播放**（B 站播放器 iframe，`BV17iEU6mE8i`，autoplay + muted，画面按 3 倍尺寸缩放塞进 74×98 小窗），带「直播 / 限时秒杀」标签和**右上角关闭 ×（只关闭本次，重新进入首页会再次出现）**；滑动时向左收进只露约 18px，停止滑动 400ms 后完整展开，收起/展开时视频继续播放。
  - 「今日上新」用**真正的瀑布流**：拆成左右两列独立 `ul`（按顺序交替分列），每列图片按 3:4 / 1:1 / 4:3 循环，右列再错开一位，两列高度自然错落；商品卡抽成 `components/ProductCard.vue` 复用（桌面栅格与移动瀑布流共用）。
  - 移动版商品卡底部固定 3 行：商品名（单行截断）/ 简介（单行截断）/ 价格 + 圆形加购按钮。
  - 「立即领奖」浮层上移到回到顶部按钮上方（bottom 128px），两者不再重叠。
  - 移动版隐藏桌面侧的搜索条、左分类栏和右侧竖向工具栏。
- **购物车页 `/cart`**（桌面版，仿京东 PC 购物车，与移动版 `/checkout` 是两个页面）：
  - 顶部：极简商城 Logo + 购物车(N) + 配送至地址 + 右侧搜索框；下方惊喜红包条。
  - 工具栏：全选（方形复选框）、删除、移入收藏、清理购物车；右侧「刚看过 / 刚收藏 / 刚买过」。
  - 店铺分组头 + 商品行（六列）：复选框、图片、标题+商品/服务两行、价格（到手价/原价/满减提示）、数量步进器、移入收藏/删除。
  - 底部固定结算条：全选（方形复选框）、已选种数/件数、清空、商品总额、共减、合计、去结算(N)（禁用）。
  - 入口：桌面右侧工具栏「购物车」。移动版底部 tab 仍指向 `/checkout`。
- **结算页 `/checkout`**（移动版仿京东购物车）：
  - 红色头部：购物车(N，N=商品种数) + 收货地址 + 对比/管理/···；下方 全部/购物/秒送(外卖)/服务(宠物) 筛选 + 搜索图标。
  - 优惠券标签行、惊喜红包提示条、店铺分组头（店铺全选框 + 自营标 + 店名）。
  - 商品行：**左侧圆形 Checkbox**、图片、名称、7 天价保险、价格、数量步进器、删除。
  - 底部满减提示条 + **结算栏（全选 Checkbox、合计 <em>只算勾选项</em>、已选件数、去结算(N) 按钮禁用）**，结算栏固定贴在底部 tab 上方。
  - 全选/单选/增减数量都实时联动合计与按钮数字；勾选状态存 localStorage（`checked` 字段）。
  - **纯前端**：存 `localStorage`，不落库、不下单支付。
- **我的页 `/profile`**（移动版仿京东个人中心 / 桌面版两栏）：
  - 桌面端（容器 >760px）：左侧固定菜单（我的京东/订单中心/我的钱包/账户设置/足迹收藏/客户服务/我的活动/特色业务/生活服务/其他业务），右侧内容区；移动版隐藏菜单。
  - 顶部：点评条 + 客服 / 地址 / 设置图标（桌面端只留图标）。
  - 用户卡：头像（用户名首字母）、用户名、会员等级（管理员 / 普通会员）、PLUS 补贴位；未登录时显示「登录 / 注册」按钮。
  - 资产行：优惠券（快过期标）/ 京豆 / 红包 / 可提现 / 秒送（外卖标）/ 更多。
  - 三块促销卡（充值更便宜 / 11.11 返场 / 直降千元）+ 每日签到条。
  - 快捷数据（足迹/收藏/关注/种草）、订单入口（待付款/待收货/待使用/待评价/退换售后/全部，带角标）。
  - 三栏服务（钱包 / 上门服务 / 互动游戏）。
  - 右侧悬浮「✦ 参与调研」按钮（贴在互动游戏区旁），点击弹出提示条「暂无进行中的调研问卷」，可关闭。
  - 功能入口（移动版）：后台管理（或「我的商品」）、消息中心。
  - 桌面端左侧菜单包含「消息中心」和「进入后台管理」（可点击跳转），页面底部入口区在桌面端隐藏。
  - 底部 tab「我的」高亮 → 本页；桌面端右侧工具栏「我的」也跳本页。
- **分类页 `/category`**（移动版，红色主题与首页一致）：
  - 顶部：红色渐变头部 + 白色圆角搜索框 + 「搜索」文字按钮。
  - 圆形分类条：横向滑动（圆形色块首字 + 名称），选中红描边、自动滚动到可见；支持鼠标滚轮横向滚动与触点滑动；右侧「展开 / 收起」可切为换行平铺全部。
  - 左栏：热卖商品（默认，全部）+ 各一级分类竖排，选中白底红字。
  - 右栏：活动 banner（首个轮播商品 + 立即抢购）、排序行（销量 / 折扣 / 价格▲▼）、快捷筛选 chips（全部 / 家电 / 手机数码，点选切换分类）、商品列表。
  - 商品行：86px 图（自营角标）、两行标题、简介、分类/回购标签、价格 + 到手价、圆形「+」加购（已加购显示数量）。
  - 底部购物车角标口径：**已勾选商品的总件数**（勾选 3 件 + 2 件 = 5；未勾选的不计）。
  - 底部 tab「分类」高亮 → 本页（原来点分类只是滚动首页分类条）。
- **商品详情页 `/product/:id`**（移动版 / PC 版双布局）：
  - **移动版**（容器 ≤760px，保持原布局）：
  - 顶部：返回箭头 + 标题「商品信息」+ ··· + 圆形图标。
  - 分区切换：「基本信息」/「图文详情」，选中红色加粗 + 红色下划线。
  - 基本信息：主图（右下 1/6 计数）与**款式缩略图条**（黑色底、选中红框），点缩略图切顶部大图，右侧显示「共 N 款 ›」；红色价格条（价格 + 距离本场结束**实时倒计时**）、商品名、提货时间、数量步进器、「商品详情」分隔线、简介文字。
  - **多图数据**：商品的 `image_url` 支持英文逗号分隔多个地址，后台录入时按此填写；单图则只显示 1 款。
  - **与购物车联动**：数量步进器直接读写购物车（该商品已在购物车时显示并修改购物车数量，减到 0 自动移除）；「加入购物车」按当前数量写入，底部购物车角标实时变化。
  - 图文详情：简介正文 + 商品大图 + 分类/录入人/上架时间。
  - 底部操作栏：分享 / 购物车（带角标）/ 加入购物车 / 立即购买。
  - 入口：首页瀑布流卡片、限时秒杀项、分类页商品行均可点进详情。
  - **PC 版**（容器 >760px，仿京东详情页）：
    - 面包屑 + 店铺条（店铺名 / 五星评分 / 关注店铺 / 联系客服）。
    - 三栏主体：左侧竖排缩略图（选中红框）、中间 1:1 白底主图（可左右切换）、右侧 460px 购买面板。
    - 购买面板：红色 11.11 促销条、标题、价格（大字价 + 划线原价 + 累计评价）、限时折扣倒计时、送至/服务信息、款式选择（多图即款式）、数量步进器、加入购物车 / 立即购买。
    - 下方白底卡片三个 tab：商品详情（描述 + 全部大图 + 分类/录入人/时间）、售后保障、买家评价（空态）。
    - 右侧固定悬浮工具栏：首页 / 购物车（角标）/ 我的 / 移动版。
    - 与移动版共用同一组件和数据，仅靠容器查询切换 DOM 与布局；移动版样式完全不变。
- 断点：≤1100px 三栏收窄；≤760px 单列，分类横向滚动，工具栏贴右侧悬浮。
  - 断点用容器查询（`.app` 为容器），不是视口媒体查询。
  - 底部 tab 栏使用半透明白 + 毛玻璃（`backdrop-filter: blur(14px)`），选中项为圆角绿色半透明胶囊（`border-radius: 14px`，再叠一层 `blur(8px)`）。

### 后台 `/admin`

- **登录 / 注册**：`/login`，注册后状态为「待审核」，人工审核通过才能登录。
- **看板**：商品总数、账号总数、累计登录次数；每个账号的登录次数、最近登录时间、上架产品数；最近 50 条登录记录。
- **商品录入**：名称、价格、分类、图片外链 URL、描述、是否首页轮播，提交后立即出现在前台。
- **商品列表**：分页查看，可删除自己录入的商品（管理员可删全部），管理员可一键切换「上轮播」。
- **账号审核**：查看全部账号状态，一键「审核通过」。

## 技术栈

| 层 | 选型 |
| --- | --- |
| 前端 | Vue 3 + Vue Router + Vite |
| 后端 | Rust + axum 0.8 + sqlx 0.8 |
| 数据库 | MySQL 8.4，库名 `pj_shop` |
| 鉴权 | JWT（Bearer，7 天有效）+ bcrypt 密码哈希 |

后端同时托管前端构建产物，**只需一个端口 5050**。

## 数据表

| 表 | 说明 |
| --- | --- |
| `users` | 账号，`status` 为 pending / approved / rejected，`is_admin` 标记管理员 |
| `products` | 商品，价格以「分」存 `price_cents`，`category` 分类，`featured` 是否进首页轮播，`created_by` 关联录入人 |
| `login_logs` | 每次登录写一条记录，供看板统计 |

表结构在服务启动时自动创建，无需手动执行 SQL。

## 本地运行

前置：Rust、Node 18+、MySQL 8，且已建库 `pj_shop`。

```bash
# 1. 前端构建
cd web && npm install && npm run build

# 2. 后端启动（默认连 mysql://root:123456@127.0.0.1:3306/pj_shop）
cd ../server && cargo run --release
```

打开 http://127.0.0.1:5050 。

自动化冒烟测试（需后端已启动；会创建一个随机测试账号并保留在库中，可自行删除）：

```bash
node smoke.mjs
```

可用环境变量覆盖配置：

| 变量 | 默认值 |
| --- | --- |
| `DATABASE_URL` | `mysql://root:123456@127.0.0.1:3306/pj_shop` |
| `JWT_SECRET` | `pj-shop-dev-secret`（生产必须改） |
| `PORT` | `5050` |
| `WEB_DIST` | `../web/dist` |

首次启动会创建管理员 `admin / 123456`，请登录后尽快修改。
